# Personal Portfolio

A modern, responsive personal portfolio website built with React, Vite, and Tailwind CSS. It showcases the developer's skills, featured projects, services, contact information, and a downloadable resume.

# Demo Link

-  https://achutakumar.github.io/My-Portfolio/

## Features

- Responsive one-page portfolio layout
- Hero section with profile overview and highlight badges
- Skills and competency section
- Featured projects showcase with live demo and source code links
- Services section for development offerings
- Contact section with phone, email, location, GitHub, and LinkedIn links
- Resume modal with PDF download option

## Tech Stack

- React 19
- Vite 8
- Tailwind CSS 4
- Lucide React icons
- gh-pages for deployment

## Project Structure

```bash
src/
  App.jsx          # Main portfolio page and UI components
  App.css          # Additional styling
  index.css        # Global styles
  main.jsx         # React entry point
public/
  img/             # Project images
  resume/          # Resume PDF files
```

## Getting Started

### Prerequisites

- Node.js 18+ recommended
- npm or yarn

### Installation

```bash
npm install
```

### Run locally

```bash
npm run dev
```

Then open http://localhost:5173 in your browser.

## Build

```bash
npm run build
```

## Deployment

This project is configured for GitHub Pages.

```bash
npm run deploy
```

This will build the app and publish the contents of the dist folder to the gh-pages branch.

## Resume

The resume PDF is stored in the public/resume folder and can be downloaded from the portfolio UI.
